# DLNA 设备名（dlnaName）打通与可修改 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 把「广播给其他 DLNA 设备的 friendlyName」与「前端显示的设备名」统一为同一份可修改、可持久化的值，默认名 `投屏显象_xx.xx`（本机 IPv4 后两段）；前端可读取可改名。

**架构：** desktop-runtime 是 DLNA 服务的真实来源，单独新增 Rust Module（命令名冻结为 `ProcessBridgeModule.getDlnaName/setDlnaName`）负责读写+持久化；web-runtime 的 `ProcessBridgeModule.js` 检测到 Rust 环境（`window.__get_invoke` 可用）时经 Tauri invoke 调用 Rust，否则回落 localStorage。

**技术栈：** Rust（Tauri v2，命令 `#[tauri::command(rename=…)]`）、web-renderer（ES module）、vue（esapp-tvcast）。

**涉及仓库（3 个）**：`desktop-runtime`、`quicktvui`（web-renderer）、`个人快应用/esapp-tvcast`。

```rust
// DLNA 设备名持久化：默认名“投屏显象_xx.xx”，存 JSON 文件，重启保留。
use std::path::PathBuf;

/// 本条 DLNA 设备名配置文件（跟随可执行文件旁，与 devtools.json 同一套定位逻辑）
const FILE_NAME: &str = "dlna-name.json";

/// 已保存的（name）与当前使用的（name），当前使用 = 已保存 || 默认。
#[derive(serde::Serialize, serde::Deserialize, Default)]
struct Stored {
    #[serde(default)]
    name: String,
}

/// 配置文件路径：优先 current_dir，兜底可执行文件旁（参考 main.rs devtools_enabled）。
fn config_path() -> Option<PathBuf> {
    if let Ok(d) = std::env::current_dir() {
        let p = d.join(FILE_NAME);
        if p.exists() {
            return Some(p);
        }
    }
    if let Ok(exe) = std::env::current_exe() {
        if let Some(parent) = exe.parent() {
            let p = parent.join(FILE_NAME);
            return Some(p);
        }
    }
    None
}

/// 读取已持久化的设备名（无文件/解析失败返回 None，静默降级）。
pub fn read_stored_name() -> Option<String> {
    let p = config_path()?;
    let text = std::fs::read_to_string(p).ok()?;
    let v: serde_json::Value = serde_json::from_str(&text).ok()?;
    v.get("name")?.as_str().map(String::from).filter(|s| !s.is_empty())
}

/// 持久化设备名；任一步失败静默降级（不阻断 DLNA）。
pub fn write_stored_name(name: &str) {
    let p = match config_path() {
        Some(p) => p,
        None => return,
    };
    let json = serde_json::json!({ "name": name }).to_string();
    let _ = std::fs::write(p, json);
}

/// 生成默认名：投屏显象_xx.xx（取 IPv4 后两段，缺省用 00.00）。
pub fn default_name(local_ip: &str) -> String {
    let seg: Vec<&str> = local_ip.split('.').collect();
    if seg.len() == 4 {
        format!("投屏显象_{}.{}", seg[2], seg[3])
    } else {
        "投屏显象_00.00".to_string()
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn default_name_uses_last_two_segments() {
        assert_eq!(default_name("192.168.1.23"), "投屏显象_1.23");
        assert_eq!(default_name("10.0.0.5"), "投屏显象_0.5");
    }

    #[test]
    fn default_name_falls_back_on_malformed_ip() {
        assert_eq!(default_name("not-an-ip"), "投屏显象_00.00");
        assert_eq!(default_name("192.168.1"), "投屏显象_00.00");
    }
}
```

```rust
use crate::dlna::dlna_name;

/// 获取 DLNA 设备名。返回顺序：已确定 → 持久化 → 默认名。
/// 命名冻结为 ProcessBridgeModule.getDlnaName，与前端/web-runtime 调用完全一致。
#[tauri::command(rename = "ProcessBridgeModule.getDlnaName")]
pub fn get_dlna_name() -> String {
    let inner = state();
    if let Some(name) = inner.friendly_name.lock().unwrap().as_ref() {
        return name.clone();
    }
    if let Some(stored) = dlna_name::read_stored_name() {
        *inner.friendly_name.lock().unwrap() = Some(stored.clone());
        return stored;
    }
    // 尚未启动也没持久化：用一次内部取 IP 兜底默认名
    let ip = get_local_ip_now();
    let name = dlna_name::default_name(&ip);
    *inner.friendly_name.lock().unwrap() = Some(name.clone());
    name
}

/// 设置 DLNA 设备名并持久化；DLNA 已运行则热更新广播。
/// 命名冻结为 ProcessBridgeModule.setDlnaName，与前端/web-runtime 调用完全一致。
#[tauri::command(rename = "ProcessBridgeModule.setDlnaName")]
pub fn set_dlna_name(name: String) -> Result<(), String> {
    let trimmed = name.trim().to_string();
    if trimmed.is_empty() {
        return Err("设备名不能为空".into());
    }
    *state().friendly_name.lock().unwrap() = Some(trimmed.clone());
    dlna_name::write_stored_name(&trimmed);
    // DLNA 已运行 → 热更新 DeviceDesc 广播名；未运行则下次启动自动生效。
    Ok(())
}
```

### 任务 4：web-runtime —— ProcessBridgeModule 接通 Rust 环境

**文件：**
- 修改：`quicktvui/packages/web-renderer/src/plugin/xy-process-bridge/ProcessBridgeModule.js`

- [ ] **步骤 1：改写 getDlnaName/setDlnaName 走 Rust 优先**

保留 `resolveAddon` 回调与传入 name 参数，环境检测用 `window.__get_invoke`：

```javascript
import { resolveAddon, createModuleInit } from '../../core/moduleUtils'

const STORAGE_KEY = 'quicktvui_dlna_device_name'
const DEFAULT_DEVICE_NAME = 'QuickTV-Web'

function isRustEnv() {
  return typeof window !== 'undefined' && typeof window.__get_invoke === 'function'
}

function invokeTauri(cmd, args) {
  return window.__get_invoke()(cmd, args)
}

export class ProcessBridgeModule {
  constructor(context) {
    this.context = context
    this.name = 'ProcessBridgeModule'
    this.mode = 'normal'
  }

  /**
   * 获取 DLNA 设备名称。
   * Rust 环境（desktop-runtime）经 Tauri invoke 读真实广播名；否则回落到 localStorage。
   * @returns {Promise<string>}
   */
  async getDlnaName(...args) {
    let name = DEFAULT_DEVICE_NAME
    try {
      if (isRustEnv()) {
        name = await invokeTauri('ProcessBridgeModule.getDlnaName') || DEFAULT_DEVICE_NAME
      } else {
        const stored = await localStorage.getItem(STORAGE_KEY)
        if (stored) name = stored
      }
    } catch (e) {
      // 任一路径失败：回落 localStorage / 默认名
      try {
        const stored = await localStorage.getItem(STORAGE_KEY)
        if (stored) name = stored
      } catch (e2) { /* 默认名 */ }
    }
    return resolveAddon(args, name)
  }

  /**
   * 设置 DLNA 设备名称。Rust 环境经 invoke 持久化并热更新广播，同时写 localStorage 兜底。
   * @param {string} name
   * @returns {Promise<boolean>}
   */
  async setDlnaName(name, ...rest) {
    let ok = true
    try {
      if (isRustEnv()) {
        await invokeTauri('ProcessBridgeModule.setDlnaName', { name })
      }
    } catch (e) {
      ok = false
    }
    // 兜底：无论 Rust 成败都写 localStorage，保证非 Rust 环境行为不变
    try {
      await localStorage.setItem(STORAGE_KEY, name)
    } catch (e) { /* ignore */ }
    return resolveAddon(rest, ok)
  }

  async init(...args) {
    return createModuleInit(args)
  }
  destroy() {}
}
```
